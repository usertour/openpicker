Pick an element, get its selector

openpicker opens a page, lets you point at any element, and hands a stable CSS selector back to the calling app — this page is a live caller of @openpicker/sdk.

Install the extension first

The demo needs the openpicker browser extension. It isn't on the Chrome Web Store yet — load it unpacked from the repo:

  1. Clone the repo and run pnpm i && pnpm --filter @openpicker/extension build.
  2. Open chrome://extensions → enable Developer mode.
  3. Load unpacked → pick packages/extension/.output/chrome-mv3.
